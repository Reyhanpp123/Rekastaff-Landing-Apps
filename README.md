# Rekastaff Landing

Marketing site for [rekastaff.com](https://rekastaff.com).

HRD / dashboard app lives separately at [hrd.rekastaff.com](https://hrd.rekastaff.com).

## Getting started

```bash
cp .env.example .env
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Env

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | This landing site URL |
| `NEXT_PUBLIC_HRD_URL` | HRD app base URL (login CTA target) |
